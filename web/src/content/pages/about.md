visose develops custom software for design, architecture, engineering, construction and manufacturing.

You work directly with the developer responsible for your software, from requirements through implementation.

## Background {#founder}

visose is led by Vicente Soler, a software developer with 15 years of freelance and consulting experience and a background in architecture.

He has also led CAD software development as CTO at H3 Space and taught computational design and robotics at UCL's Bartlett School of Architecture, where he directed the Architectural Computation MSc/MRes program.

[Vicente Soler on LinkedIn](https://www.linkedin.com/in/visose/)

## Technical expertise {#technical-expertise}

Our work combines software engineering with computational geometry, computer graphics and robotics.

### Software engineering {#expertise-software}

We design and build web and desktop applications, backend services and APIs. We work with C#/.NET, TypeScript and React.

### Geometry and graphics {#expertise-geometry}

We build software for solid and mesh modeling, parametric design and interactive 3D. We work with libraries such as Three.js for browser graphics.

### CAD integrations {#expertise-integrations}

We build custom tools and integrations for platforms such as Rhino, Grasshopper, Revit, Navisworks and SketchUp.

### Robotics {#expertise-robotics}

We develop software for robot kinematics, toolpath generation, simulation and process control.

### Cloud and delivery {#expertise-delivery}

We build and deploy software on cloud platforms such as AWS and Azure. We use automated testing and continuous integration to support releases.

## Open-source software {#open-source-software}

We created and maintain [Robots](/projects/robots), an open-source robot-programming library for Rhino, Grasshopper and .NET. Originally developed at UCL, it has been used at more than 70 universities and design schools worldwide.
