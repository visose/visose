# visose

I develop custom CAD and 3D applications, plugins and robotics software for design,
architecture, engineering and manufacturing. My work spans C#/.NET, TypeScript,
computational geometry and computer graphics.

## Robots

I created and maintain [Robots](https://github.com/visose/Robots), an open-source
library for programming and simulating industrial robots in Rhino, Grasshopper
and .NET. Originally developed at UCL, it has been used at more than 70 universities
and design schools worldwide.
